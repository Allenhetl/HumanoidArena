This directory keeps historical or comparison-only eval launch scripts that are not the primary user entrypoints.

Primary maintained entrypoints live in `isaaclab_twist2_g1/`:

- `batch_1_test_v31_sonic.sh`
- `batch_1_test_v31_twist2.sh`
- `batch_1_test_v31_merage.sh`
- `batch_pi05_v31_sonic.sh`
- `batch_pi05_v31_twist2.sh`

The scripts here are examples for cross-backend, merged-checkpoint, or path-specific experiments. Treat hard-coded checkpoint paths as examples and update them before reuse.
