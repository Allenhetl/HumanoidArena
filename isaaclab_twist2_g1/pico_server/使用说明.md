## 故障排除

### 问题1: Encoder推理失败
```
Error: Failed to run encoder inference
```

**检查**:
- encoder模型路径是否正确
- encoder输入维度是否为1762
- 运行 `check_sonic_encoder.py` 验证模型

### 问题2: 输出仍然是固定值
```
sonic_targets: [-0.312 -0.312 0. ... 0. 0. 0.]
```

**检查**:
- SMPL数据是否有效（`_smpl_data_valid` 应该为True）
- ZMQ是否正常接收数据
- 运行 `diagnose_sonic.py` 检查数据流

### 问题3: 维度不匹配错误
```
Error: Input dimension mismatch
```

**检查**:
- 运行 `test_encoder_input.py` 验证输入构建
- 检查 `observation_config.yaml` 是否与代码一致

### 问题4: Pico数据未接收
```
waiting for body data...
```

**解决**:
- 确保Pico设备已开机并运行身体追踪应用
- 检查 `roboticsservice` 是否运行
- 重启Pico服务器

## 技术细节

### Encoder输入格式
- **总维度**: 1762
- **格式**: 单个1D向量 `(1, 1762)`
- **内容**: 14个观察值按顺序拼接

### 6D旋转表示
- **来源**: 旋转矩阵R的前2列
- **格式**: `[R00, R01, R10, R11, R20, R21]`
- **优点**: 连续、无奇异点、适合神经网络

### SMPL模式
- **mode_id**: 2
- **encoder_mode**: `[0, 0, 1, 0]`
- **关键输入**: SMPL joints + 6D rotation + wrist positions
